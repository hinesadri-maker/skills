# Adrienne's Claude Skills

Ready-to-install skills for Claude. Each one is a folder with a `SKILL.md` inside. Grab the zip, upload it, done.

## Install in Claude

1. Click a **Download** link below (or open the `zips/` folder and pick one).
2. In Claude, go to **Settings → Capabilities → Skills → Upload skill**.
3. Choose the zip. The skill is live in your next chat.

Want to use one with Claude Code instead? Unzip it into `~/.claude/skills/`.

## Make your own zip from any folder here

GitHub can't zip a single subfolder, so: open the skill's `SKILL.md`, click **Raw**, save it as `SKILL.md` inside a folder named after the skill, then compress that folder. Upload the result the same way.
